Calculadora gratuita de cafeína

Usa el tracker web para estimar cuánta cafeína sigue activa después de café, té, bebidas energéticas o cantidades personalizadas. El gráfico muestra una curva de cafeína estilo Garmin para el día actual.

Cómo funciona la estimación

La calculadora aplica la degradación por vida media de la cafeína y ajusta la estimación con tu peso corporal. Para más detalles, lee cómo funciona Caffeine Tracker.

Úsalo antes de instalar en Garmin

Prueba diferentes bebidas, horarios, ajustes de vida media y umbrales seguros para dormir antes de usar el mismo modelo en el widget de Garmin Connect IQ.

Almacenamiento privado en el navegador

Las bebidas y los ajustes se guardan localmente en este navegador. El tracker es una estimación para planificación personal y no es consejo médico.

FAQ del tracker de cafeína

¿Este tracker de cafeína es un análisis de sangre?

No. Es una estimación basada en un modelo que usa las bebidas registradas, tu peso corporal y la vida media de cafeína seleccionada.

¿El tracker web guarda mis datos en un servidor?

No. Las bebidas y los ajustes se guardan localmente en tu navegador.

¿Cómo elijo una vida media de cafeína?

Usa el asistente de vida media de cafeína para estimar un ajuste práctico y luego aplica ese valor en el tracker web o en el widget de Garmin.
